# Compact result tables

These files provide human-readable aggregates and the complete 90-row Lead
audit table. They are convenient for plotting and checking dissertation
claims, but they are not a replacement for the raw Zenodo evidence.

- `elastic_loflex_3seed.csv`: delivered de novo aggregate.
- `constraint_factorial_3seed.csv`: raw FSM/RDKit 2x2 ablation.
- `native_final_v4_base50k_3seed_*.csv`: fragment aggregates.
- `lead_final_score_summary.csv` and `lead_audit_runs.csv`: Lead matrix.
- `pmo_overall_3seed.csv` and `pmo_by_task_3seed.csv`: PMO aggregates.
